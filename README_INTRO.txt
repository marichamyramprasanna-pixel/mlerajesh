OPENING TITLE SCREEN

When the application is opened, it first shows a professional title/initialization screen for about 5 seconds, then automatically opens the existing dashboard.

The existing dashboard wording, stages, controls, machine status, and diagnosis interface are unchanged.

To use:
1. Extract the package.
2. Double-click Launch_Machine_Fault_Diagnosis_App.bat.
3. The title screen appears first, then the dashboard opens automatically.
4. Run Create_Desktop_Shortcut.bat once to create the desktop shortcut with the project icon.
